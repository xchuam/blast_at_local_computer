# Three-Assembly Datasets Example

This folder contains small files from a successful three-assembly `datasets-download` test run.

Included:

* `resolved_accessions.txt` - accessions extracted from the input TSV
* `batches/ncbi_dataset_batch_00001.txt` - batch input passed to `datasets`
* `batches_manifest.tsv` - batch status and package paths
* `download_commands.sh` - generated command for audit or rerun
* `ncbi_dataset/data/assembly_data_report.jsonl` - assembly metadata from the NCBI Datasets package
* `ncbi_dataset/data/dataset_catalog.json` - file catalog from the NCBI Datasets package
* `md5sum.txt` - package checksum file

Not included:

* downloaded zip packages
* genomic FASTA files
* GFF3 files
* GTF files

Those files are generated by running `python src/blast_at_local_computer.py datasets-download ... --extract`.
